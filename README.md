# TijAl Delivery

A delivery service website for customers in Adamawa State, Nigeria. The project includes a customer website and an admin dashboard.

## Project files

- `tijai-separated-project/index.html` — customer website
- `tijai-separated-project/admin.html` — admin dashboard
- `tijai-separated-project/assets/` — website styles and scripts

## Run locally

Open `tijai-separated-project/index.html` with VS Code Live Server. To view the admin dashboard, open `tijai-separated-project/admin.html`.

This is a front-end learning demo built with HTML, CSS, and JavaScript.
